---
name: Supplier invitation review
description: Approval boundary for invited supplier profile changes and submitted product photos.
---

Invitation completion must only create a review request. Do not write the submitted supplier fields to the live supplier record; keep submitted photos attached to the request as review evidence.

**Why:** An invitation can target a supplier with an existing active public profile. Applying unreviewed edits immediately would expose them before moderation.

**How to apply:** Keep newly invited drafts and changes to existing suppliers behind the same admin approval step. Only promote profile fields from the request during approval; if public image publication is added, do it in that same approval path.
