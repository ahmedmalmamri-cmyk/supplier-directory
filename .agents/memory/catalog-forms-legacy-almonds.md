---
name: Catalog forms and legacy almonds
description: Non-destructive form taxonomy convention and compatibility with old almond options.
---

Each existing catalog master has at least one form: an item-scoped neutral default where a more precise shape has not been curated. Optional attributes and their values belong only to that master. A supplier declares a form and any attribute selections on an individual offer, so exact buyer filters must match that same eligible offer.

**Why:** Requiring an administrator to classify every historical item before the supplier can declare an offer would stall the already-empty directory. The legacy almond taxonomy consists of separate items for whole, sliced, and ground almonds; merging or renaming those IDs would break links and existing filters.

**How to apply:** Show the three almond items together as one buyer-facing shape choice while retaining the old IDs and legacy almond URL/filter semantics. Never infer an attribute value from a form or from a supplier’s unrelated offer. The neutral form is a transitional selection, not a stock claim.
